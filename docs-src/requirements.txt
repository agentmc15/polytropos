# Locked site toolchain — bin/ and tests/ stay stdlib-only (CLAUDE.md invariant).
#
# Every package, including transitives, is pinned to an exact version with the sha256 of the
# artifact CI will download. `pip install --require-hashes` refuses anything that does not
# match, so a compromised or substituted artifact fails the build instead of running in it.
# `mkdocs-material>=9.5,<10` alone pinned neither a version nor a transitive set: two runs a
# week apart could install different code.
#
# Resolved for the CI runner (linux x86_64, CPython 3.12) — the platform
# `.github/workflows/docs-site.yml` pins. Regenerate after changing the top-level requirement:
#
#   python3 -m pip install --dry-run --report lock.json --ignore-installed \
#     --only-binary=:all: --platform manylinux2014_x86_64 --python-version 3.12 \
#     --target /tmp/discard 'mkdocs-material>=9.5,<10'
#
# then rewrite this file from lock.json's install[].metadata and download_info.archive_info.
# Nothing here is installed outside CI or a throwaway virtualenv.
